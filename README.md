# 炎明 YM · 个人作品集（单文件版）

整站内联为单一 HTML，零外部依赖，断网 / 双击 / 直接托管均可完整显示。

- 头图：鼠标移动揭出全彩人像的抖纱（dither veil）效果，点击出彩色波纹
- 项目卡：悬停 3D 样机；证书墙：滚动逐个浮现
- 全部 CSS / JS / 图片已内联，无任何外链资源

## 本地预览
直接双击 `index.html` 即可。

## 部署到 GitHub Pages
1. 在 GitHub 新建一个公开仓库（例如 `portfolio`）。
2. 把本目录内容推送上去：
   ```bash
   git remote add origin https://github.com/<你的用户名>/<仓库名>.git
   git push -u origin main
   ```
3. 仓库 **Settings → Pages**，Source 选 `main` 分支、目录选 `/（root）`，保存。
4. 几分钟后访问 `https://<你的用户名>.github.io/<仓库名>/` 即可。

> 文件约 2.5MB，全部为内联资源，GitHub 单文件上限 100MB，完全没问题。
